# PlusOnes — website (Netlify Drop)

Structuur:
- `index.html` — de startpagina
- `css/style.css` — alle opmaak
- `js/script.js` — menu, NL/EN-schakelaar, animaties, cases-carrousel, FAQ en formulier
- `images/` — afbeeldingen als WebP
- `fonts/` — Poppins en Public Sans (woff2)

## Online zetten
Sleep deze map (of de zip uitgepakt) naar https://app.netlify.com/drop.

## Nog te doen
- Het contactformulier opent een mail aan joep@plusones.ai. Voor directe ontvangst: voeg `data-netlify="true"` en `name="contact"` toe aan het `<form>` en verwijder de mailto-regel in `js/script.js`.
- De link "Privacyverklaring" wijst nog naar `#privacy`.
- Video: op de plek van de hero-afbeelding staat een commentaar waar een YouTube/Vimeo-embed kan komen.
